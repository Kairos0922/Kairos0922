The Learning Loop

当答案随手可得，真正值得练习的是：怎样把未知变成可解决的问题。

学习不是囤积结论，而是发现、定义、建模、检验、修正，再把方法带到下一个未知。

一题练习 · 纸飞机刚离手就俯冲

先看见发生了什么

先写下可重复描述的现象，不急着解释原因。示范情境：纸飞机刚离手，就朝地面俯冲。

这一阶段要做的事暂时把「为什么飞不好」放一边，只留下能观察到的现象。
